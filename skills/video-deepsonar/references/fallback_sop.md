# 视频抽帧与 ASR 兜底最佳实践 SOP（纯文本/无 ffmpeg 环境实战指南）

> **适用场景**：
> 当 Agent 运行在无全模态能力（如 DeepSeek、纯文本 Agent）、环境无云端多模态 API Key、且宿主机**未安装 ffmpeg / ffprobe / homebrew** 的极限受限环境时，按本规程以最低时间成本完成分镜拆解与口播逐字稿还原。
>
> 沉淀自生产真实踩坑（避开 10 大硬坑，时间从数小时收敛至可控流水线）。

---

## ⚡ 核心认知与三条硬规则

1. **音画解耦，并行推进（时间最优原则）**：
   抽帧与音频导出为**秒级操作**，而 CPU 上的离线 ASR 为**分钟级操作（约 7~9 分钟）**。
   **切禁串行傻等 ASR！** 秒级导出的 `audio.wav` 必须立即丢入后台执行 ASR，前台立刻并行开展画面通览、0.5s 拼图定边界与实物文字局部放大核读。
2. **画面优先于听觉（音画互证闭环）**：
   ASR 听写存在音近字误差，但实物包装备案名、检测报告编号等高清晰度画面**绝无音近误差**。两方信息冲突时，以可放大核验的画面实物文字为绝对准绳反向锁定口播。
3. **切点检测是索引不是结论**：
   自动切点算法（基于帧间差分）对主播伸手、运镜旋转极度敏感，误报率高；切点仅作为缩小视觉复核范围的索引，严禁未经人工核对直接作为最终分镜。

---

## 一、 环境极速就绪（免系统 ffmpeg / 免 brew）

不要尝试在受限环境去装 Homebrew 或编译 ffmpeg，使用 **PyAV** 纯 Python Wheel 自带动态链接库即可一统音视频解包：

```bash
# 激活或创建环境，一次性装齐 4 大依赖（切勿漏装 numpy）
pip install -q av pillow numpy faster-whisper
```

> ⚠️ **避坑 1（漏装 numpy）**：PyAV 虽然基础解包不用 numpy，但帧间差分切点检测和 PCM 音频分段切片强依赖 numpy。必须一次装齐。

## 二、 时序最优流水线（Time-optimal SOP）

```
[步骤 1: 秒级提取]
  使用 PyAV 抽帧并导出 16kHz 单声道 audio.wav
        │
        ├─────────────────────────────────────────┐ (分流并行)
        ▼                                         ▼
[步骤 2: 后台挂起 ASR] (耗时 7~9 分钟)      [步骤 3: 前台画面核读] (耗时 3~5 分钟)
  • faster-whisper medium 档                • 读均匀帧确认「画面有无烧录字幕」
  • 走 hf-mirror 镜像                       • 0.5s 细粒度拼图裁定物理分镜边界
  • CPU + int8 量化 (后台静默执行)           • L3 定向取帧：包装/内卡/检测报告
        │                                   • 浮雕文字：3x 局部放大 + 旋转 90°
        │                                   • 沉淀《画面锁定的高确定性信息清单》
        ▼                                         │
[步骤 4: ASR 回归与两级纠错] ◄────────────────────┘
  ├─ 第一级：存疑时间段切片 + 预期领域词 initial_prompt 偏置重听
  └─ 第二级：用《画面清单》反向锁定口播品名与成分，杜绝音近幻觉
        │
        ▼
[步骤 5: 组装输出 work/lacing_result.json (标注 mode: fallback)]
```

## 三、 抽帧与画面核读最佳实践

### 3.1 三级分层抽帧策略
| 层级 | 粒度 | 核心用途 |
| :--- | :--- | :--- |
| **L1 均匀帧** | 1.0 秒 / 帧 | 快速通览全片剧情与结构，**首先确认有无烧录字幕**（无字幕严禁等待 OCR） |
| **L2 切点候选** | 6 fps 采样 + 帧间差分 | 找出疑似转场候选点（仅供定位索引，需人工复核） |
| **L3 定向高清帧** | 精确时间戳毫秒取帧 | 核读包装微小备案名、检测报告编号、页码及水印角标 |

### 3.2 0.5 秒网格拼图（Contact Sheet）
1.0 秒帧无法精确定位 0.3 秒以内的快速跳切。将视频按 **0.5 秒粒度**（如 136 帧）快速拼成 6 列的网格接触印相（如 24 帧/张），**看 5~6 张拼图即可在 1 分钟内手工快速敲定全片 18~25 镜的起止秒数**。

### 3.3 浮雕与微小文字核读技巧
- **局部 3.0~4.0 倍放大**：2.0 倍时低对比度字母依然模糊，逐步加大放大倍率；
- **旋转 90°（针对竖排/环形浮雕）**：外盒包装凹凸压印字母多为立式排布，旋转 90° 后才可辨认（如 `uniquederma`）。
- ⚠️ **避坑 4（路径 ENOENT 陷阱）**：定向取帧**必须落入全新目录**，绝不要复用同名旧目录覆盖写入，否则沙箱文件系统会出现 `listdir` 可见但 `Image.open` 报不存在的诡异文件状态异常。

## 四、 ASR 离线转录与两级纠错

### 4.1 模型选型红线
- ❌ **small 档（461 MB）**：中文垂类词汇系统性崩溃，会把核心“痘”字全面替换为“斗”（如“消豆机底液/经济暴斗/斗印”），严禁用于电商风控。
- ✅ **medium 档（1.42 GB）**：**本项目基准档位**，兼顾推理速度与词汇覆盖；
- ❌ **macOS 原生 Speech 框架**：命令行无 App Bundle 签名，调用即被 TCC 权限模型 SIGABRT (exit 134) 强杀，不可使用。

### 4.2 执行参数标配（faster-whisper）
```bash
# 1. 必须使用镜像源防卡死
export HF_ENDPOINT=https://hf-mirror.com

# 2. Mac 平台强制 CPU + int8（CTranslate2 在 Mac 上不支持 Metal/CUDA）
python3 scripts/run_asr_fallback.py audio.wav -o work/asr_raw.json --model medium
```

### 4.3 两级纠错闭环（从能用到可交付的关键）

#### 第一级：存疑片段切片 + 领域词偏置（`initial_prompt`）
不重跑全片，仅截取存疑时间段 PCM 音频切片，注入预期领域词：
```python
segs, _ = model.transcribe(
    "_slice.wav",
    language="zh",
    beam_size=8,                      # 增大搜索宽度
    temperature=0.0,                  # 关闭采样随机性，结果确定
    condition_on_previous_text=False, # 切断上下文，防前文错字污染
    initial_prompt="优研达这套双维度净痘套组，痘肌才懂它的价值" # 注入领域词偏置
)
```
> ⚠️ **偏置防幻觉铁律**：`initial_prompt` 必须基于常理与上下文音近推导，绝不可注入凭空编造的词，否则模型会产生迎合式幻觉。

#### 第二级：音画互证（画面反向校准）
将画面 L3 提取的高确定性实物信息直接比对 ASR：
- 画面拍到包装印刷品名为 `优研达净透控油精华液`；
- ASR 听写显示为 `消痘肌底液`；
- **裁决结论**：口播确实念了“消痘肌底液”（涉嫌私改备案品名超范围宣称），二者不一致正是风控核心命中点！

## 五、 10 大避坑红线速查表

| # | 踩坑现象 | 根本原因 | 唯一正确对策 |
|---|---|---|---|
| **1** | 切点检测报缺少 numpy | 安装清单不完整 | 初始即运行 `pip install av pillow numpy faster-whisper` |
| **2** | 自动切点数量爆炸（如 >35 个） | 帧差算法对运镜晃动误报 | 切点集只做缩写复核范围的索引，严禁当分镜结论 |
| **3** | 浮雕文字成模糊色块 | 低对比度与竖排排版 | 局部放大 ≥3.0× 并配合旋转 90° 阅读 |
| **4** | 文件读取报 ENOENT 不存在 | 复用同名旧目录导致沙箱状态不同步 | 每次定向抓帧均生成全新目录，不覆盖旧文件 |
| **5** | HuggingFace 模型下载无限卡住 | 直连网络受限 | 强制配置环境变量 `HF_ENDPOINT=https://hf-mirror.com` |
| **6** | Mac 报错或无 GPU 加速 | CTranslate2 在 macOS 不支持 Metal | 强制指定 `device="cpu"` + `compute_type="int8"` |
| **7** | ASR 出现“暴斗/机底液” | small 档中文垂直词汇崩溃 | 坚决使用 `medium` 档位作为起步基准 |
| **8** | Swift 原生语音调用闪退无日志 | macOS TCC 隐私权限杀掉 CLI 进程 | 放弃系统 Speech 框架，改用完全自包含的 faster-whisper |
| **9** | 傻等 OCR 导致整条管线停滞 | 先入为主假设视频有字幕 | 抽帧后第一步先看 1s 均匀帧确认画面有无内嵌字幕 |
| **10**| 废弃模型残留占满磁盘 | 调试多档位未清理 | 确定使用 medium 后立即清理 `~/.cache/whisper-ct2/` 旧档 |

## 六、 验收交付标准
1. **分镜密度**：60~70s 电商视频最终分镜必须收敛在 **18~25 镜**区间（典型约 21 镜），不得粗切成 7~10 个粗镜头；
2. **时间连续**：分镜时间码单调递增首尾相接，起始 0.0，结束准确对齐总时长；
3. **标记规范**：拉片 JSON 的 `model_used.mode` 显式注明 `"fallback"`，提示人工抽查核心违规帧。
