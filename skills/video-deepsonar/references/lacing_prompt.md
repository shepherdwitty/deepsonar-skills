# 标准化拉片 Prompt 与输出 Schema（唯一真源）

> 本文件同时是**喂给多模态模型的完整 prompt 原文**（`call_lacing_model.py --prompt-file` 直接读取）
> 与拉片输出 JSON schema 的契约文档。字段名不得改写、不得增删。

---

## Prompt 原文（以下整段即 prompt，喂模型时原样使用）

你是一名专业的电商短视频全模态拉片与风控归因专家。请对输入的抖音带货短视频做**全模态端到端逐镜头深度拆解**，并以**严格 JSON** 输出，禁止输出 JSON 以外的任何说明文字或 Markdown 围栏。

### 核心拉片原则：时序视觉优先（Visual Cut First）

1. **【最高铁律】分镜边界必须严格依据画面物理剪辑点，严禁按口播台词断句合并镜头！**
   - 分镜切分的唯一依据是画面的**机位切换、景别跳切（全景/特写/微距）、特写插切、主体动作突变、场景/道具更迭**；
   - **绝不允许以口播句号或台词停顿合并镜头**！一句台词跨越多个画面动作时，**画面一切，分镜必切**（例如：前 1 秒主播手扶刘海发夹，后 1 秒画面瞬切为旋转笔尾出液特写，必须切为两个独立分镜；台词在各自分镜中按时间截断或承接）；
   - 电商短视频节奏极快，切片粒度密集在 **1~3 秒**（60~70 秒视频通常包含 **18~25 个分镜**，典型为 21 镜左右）。绝不允许宏观粗切成 7~16 个大镜头！

2. **【微视觉动作与道具交互高精捕捉】**：
   - **主播装扮与微动作**：如“固定刘海的发夹/戴发箍/裹干发帽”、“白纱上衣”、“指腹按压脸颊红点”、“涂抹手法”；
   - **产品机械结构与使用动作特写**：如“旋转展示祛痘笔尾部出液结构”、“手背涂抹肌底液推开质地”、“挤出乳白色膏体质地”、“滴管吸取精华”等动作细节；
   - **资质证据与实验图表闪切（即使仅露 1 秒也必须独立成镜，风控铁证）**：
     - **检测报告/图表**：如“PONY/微谱第三方测试报告柱状图”、“折线对比图”、“检测机构印章”；
     - **报告文字与数据**：报告编号、页码指示（如「第 14 页/共 61 页」）、实验数据与时间条件（如「8 小时 -35.90%」）、检测机构全称；
     - **水印与角标**：如「内部文件」「仅供资质审核」「仅供参考」「广告」等角标水印原样记录；
   - **包装印刷实物文字**：瓶身/外盒实际印刷品名（如「优研达净透平衡套装」「优研达净颜控油精华液」）、规格净含量（如 30ml/支），逐字记录以核验宣称品名一致性。

3. **【口播与宣称高精还原】**：
   - `audio` 记录该镜头时间窗内的声音（口播原句片段/BGM/音效，允许无口播）；
   - `claims` 原样摘录功效、绝对化用语、对比贬损、资质背书等风险宣称（如“三天祛痘”“从根源稳住”“第三方检测报告认证”“一停就反弹”）；
   - 另附全片 `transcript` 逐句转录（标注起止秒数，保留 1 位小数，听不清标 `[无法辨认]`，严禁臆造补全）。

4. **【时序连续性与格式约束】**：
   - 时间戳严格单调递增，`shots` 首尾相接覆盖全片，起始于 0.0，结束于视频实际总时长；
   - 镜头编号 `id` 从 1 开始连续递增，只输出一个纯合法的 JSON 根对象。

### 输出 JSON Schema

```json
{
  "video_meta": {
    "platform": "douyin",
    "duration_sec": 67.9,
    "shot_count": 21,
    "title_guess": "依据画面/口播推断的视频主题，一句话"
  },
  "transcript": [
    {"start": 0.0, "end": 1.6, "text": "口播原句"}
  ],
  "shots": [
    {
      "id": 1,
      "start": 0.0,
      "end": 1.9,
      "visual": "景别与客观画面描述（如：特写，女生手扶刘海发夹，面带微笑面对镜头）",
      "on_screen_text": ["画面字幕", "包装文字", "报告角标"],
      "audio": "口播原词片段 / BGM / 特效音",
      "claims": ["宣称原句"]
    }
  ],
  "full_transcript_text": "口播全文纯文本拼接",
  "all_on_screen_text": ["去重后的全部屏幕/包装/报告文字"],
  "claims_summary": ["去重后的全部风险与功效宣称"],
  "model_used": {"provider": "gemini", "model": "gemini-3.8-flash", "mode": "direct", "latency_sec": 0}
}
```

## Agent 侧校验清单（拿到拉片 JSON 后逐项自查）

- [ ] **时序分镜粒度核查**：检查总镜头数是否达到电商短视频标准密度（60~70s 视频通常在 18~25 镜，典型约 21 镜；若低于 16 镜，高度警惕是否发生“按口播台词粗暴合并镜头”，必须回退重新按画面切分）；
- [ ] **微视觉切镜核查**：确认是否捕捉到关键动作（如发夹固定、旋转笔尾出液特写、手背推开质地、乳白色膏体特写等 1~2 秒切片）；
- [ ] **资质与图表闪切核查**：确认第三方检测报告柱状图/折线图露出时是否独立成镜，机构名与报告编号是否原样转录；
- [ ] **时序单调连续性**：`shots` 起止时间首尾相接覆盖全片，不漏秒、不超 `duration_sec`，`id` 从 1 连续编号；
- [ ] **文本真实性**：`full_transcript_text` 严禁臆造，看不清处使用 `[无法辨认]`；
- [ ] `model_used.mode` 与实际通道一致（direct / fallback）。

校验不过的拉片结果不得进入 MCP 归因阶段；重试或重新按视觉切镜直出。
